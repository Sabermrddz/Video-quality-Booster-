Pipeline

Three steps, zero dollars

Browsers, a tiny Node queue, and one free GPU notebook do all the work.

01

Upload your clip

The browser validates length and size, then PUTs the file straight to private B2 storage with a presigned URL.

02

GPU worker enhances ×4

A Kaggle notebook polls the queue, runs pretrained Real-ESRGAN on every frame and uploads the result.

03

Compare & download

The page shows a draggable before/after slider, the measured processing time, and a download button.

Built like a product

Everything you'd expect from a real tool

Even though the whole pipeline costs zero dollars to run.

Pretrained GAN

Real-ESRGAN realesr-general-x4v3 — battle-tested 4× super-resolution, weights download automatically.

Free GPU pipeline

Kaggle's T4/P100 does the heavy lifting. No cloud GPU bill, no API keys on the worker — just presigned URLs.

Private by design

Files live in a private Backblaze B2 bucket behind short-lived presigned URLs. B2 keys never leave the server.

Live status & logs

Progress ring, step timeline and a live worker log stream while your clip is in flight — no page refreshes.
